# Welcome to AB Talks 👋

> **Building practical AI through open-source collaboration, real-world projects, and learning in public.**

AB Talks is a community of students, developers, creators, and professionals building AI that solves real-world problems.

We believe the best way to learn AI isn't by collecting certificates or watching tutorials. It's by building projects, sharing your work publicly, collaborating with others, and continuously improving.

---

## 🚀 What You'll Find Here

This organization hosts open-source projects developed by the AB Talks community.

Current focus areas include:

- 🤖 AI Agents
- 🛠 AI Applications
- 📦 Starter Templates
- 📚 Learning Resources
- 💻 Community Projects

Every repository is designed to be practical, reusable, and beginner-friendly.

---

## 🌱 Our Philosophy

Build → Share → Learn → Improve

We encourage building in public because it creates:

- Real projects instead of tutorial dependency
- A verifiable portfolio
- Open collaboration
- Faster learning through feedback
- Code others can learn from
